# DeepSeek 语音助手

本应用以独立的语音对话界面替换硬件测试启动页。ESP32-C3 采集麦克风输入，
显示识别文字和 DeepSeek 回答。同一份固件支持中文及两种连接方式。
回答以文字显示，支持可选的腾讯云 TTS 语音播放及音量设置，尚未实现唤醒词。

腾讯云 TTS 将长回答优先按句末或单词边界分成每段不超过 120 个 Unicode 字符的
文本，不截断 UTF-8 字符。各段依次合成和播放，流式输出 PCM，不在内存中保存
整段音频。停止播放会取消后续段落。任一段失败会停止播放，并显示云端错误码
或本地、HTTP 错误，不再一律提示未开通服务。

| 模式 | 网络路径 | 持久记忆 | API 密钥 |
| --- | --- | --- | --- |
| 电脑服务 | 设备 → 电脑 → 语音识别 → DeepSeek | 电脑 SQLite，最近 12 轮作为上下文，最多保留 128 轮 | 保存在电脑 |
| 设备直连云端 | 设备 → 语音识别 → DeepSeek | 设备 NVS 最近 3 轮，每条问答设有 UTF-8 字节上限 | 保存在设备 NVS |

两种模式都使用在线语音识别。默认使用腾讯云「一句话识别」及 `16k_zh` 引擎，
仍支持已有的兼容 multipart 转写接口。DeepSeek 默认使用
`deepseek-flash`，关闭思考并限制回答长度。云服务可能按服务商规则收费。
交付固件不包含编译进去的服务密钥。

## 按键操作

两种连接方式共用 `main/assistant_persona.txt` 中的洛天依角色提示词，保留所提供
人设中温柔、元气、喜欢美食的风格，并限制小屏回答长度，只参考实际提供的对话
历史。设备不会声称已经唱歌；被问及身份时说明是非官方 AI 助手。
所提供的完整人物资料保存在[洛天依人物设定](luo-tianyi-persona.zh_CN.md)。

- 短按**确定**开始请求，等录音提示出现后说话。麦克风以 16 kHz、单声道、
  16 位有符号 PCM 边录边传，最长 8 秒。再次短按**确定**提前结束，剩余上传
  用静音补齐以保持固定长度。
- 短按**上/下**滚动对话。
- TTS 播放过程中短按**确定**停止，短按**上/下**调节音量。
- 空闲时长按**确定**，重启进入设置。
- 空闲时长按**下**请求清除当前模式的记忆，再短按**确定**确认，或短按**上/下**取消。
  清除电脑模式的记忆需要电脑服务在线；设备本地记忆可离线清除。
- 网络请求过程中忽略其他操作。不会自动重试请求，避免结果不明时重复调用付费服务。

界面以 `#66CCFF` 为主色，采用更鲜艳的配色，并将助手消息标记为“洛天依”。
界面包含连接、录音、识别、思考、错误状态，可滚动对话、清除确认及右上角电量。
读不到电量时显示不可用。

## 首次设置及切换模式

1. 经明确授权烧录后开机。没有有效配置时设备创建 `Passport-XXXXXX` WPA2 热点，
   固定的设置热点密码显示在设备屏幕上。
2. 手机或电脑连接该热点，打开 `http://192.168.4.1`。手机提示无互联网时仍需保持连接。
3. 输入 2.4 GHz Wi-Fi 名称、密码，选择模式。电脑模式输入电脑局域网基础地址，
   例如 `http://192.168.1.100:8765`，并填写与电脑服务一致的设备令牌。不要填写
   `localhost`，也不要附加 `/v1/voice`。直连模式输入 DeepSeek API Key、腾讯云
   SecretId 和 SecretKey；高级设置可修改完整接口地址及模型名称。
4. 保存后设备重启、关闭配置热点并连接 Wi-Fi。手机恢复原来的 Wi-Fi，短按确定测试一句话。
5. 空闲时长按确定重新设置或切换模式。可以沿用已保存的 Wi-Fi，API 配置需重新填写，网页不会读回已有密钥。
   如果进入设置后未保存就关机重开，会恢复之前的配置。

设置页也支持选择本地图片作为壁纸。浏览器会将图片居中裁切为竖屏比例，转换成
240×320 RGB565 后只上传转换结果，设备不会保存原图。应用或清除壁纸后设备自动
重启；上传中断产生的数据不会被当成有效壁纸，界面会退回内置 `#66CCFF` 主题。

配置通过校验才写入存储。正常连接路由器时不会在该网络开放配置服务器。
直连云端强制 HTTPS 并验证证书，请求前通过 NTP 校时。电脑服务的 HTTP 仅用于
可信局域网；跨不可信网络时应使用带公开受信任证书的 HTTPS 反向代理。
路由器的客户端隔离可能阻止设备访问电脑。

配置网页默认使用设备直连云端。主界面只展示已保存的 Wi-Fi、DeepSeek 密钥、腾讯云 SecretId/SecretKey 和一个
主要保存按钮。电脑服务模式、接口地址及模型名称收在**更多设置**中。网页同时
显示三步设置说明和设备按键用法。

## 主 Wi-Fi 与备用 Wi-Fi

网页支持一个主网络和一个可选备用网络。勾选**启用备用 Wi-Fi**，填写不同的
2.4 GHz Wi-Fi 名称和密码，点击**只保存 Wi-Fi 设置**即可保留原有 API 密钥和角色设置。
`GET /wifi` 不会返回任何密码。网页支持沿用已保存的备用网络、更换备用网络，
或取消勾选并保存以删除备用网络。密码留空表示开放网络；名称最多 32 个 UTF-8 字节，
非空密码为 8–63 字节。保存其他设置会保留备用网络。

每次开机优先连接主网络，连续连接失败 3 次后切换备用网络；备用也失败 3 次后
再次尝试主网络。取得 IP 地址后清零失败次数，并保持当前已连接网络，不打断正常
工作的备用网络去探测主网络。切换依据是 Wi-Fi 断连，不是云服务错误，也不是
Wi-Fi 仍关联时的互联网中断。已有的 30 秒超时提示本身不会触发切网。

备用凭证改为保存在 NVS 配置中，不再使用 `main.c` 里的固定宏。旧配置迁移保留
主 Wi-Fi、API 密钥、角色、TTS 及音量；首次升级后备用网络默认关闭，需在网页配置一次。
原来写死的备用网络不会自动复制进持久化配置。切换策略位于 `assistant_wifi_policy.c`；
主循环负责调用 Wi-Fi 驱动，只有驱动接受配置后才更新所选网络。

## 腾讯云配置与旧版迁移

1. 在[腾讯云语音识别控制台](https://console.cloud.tencent.com/asr)开通**一句话识别**。
   [当前计费规则](https://cloud.tencent.com/document/product/1093/35686)提供每月 5000 次
   成功识别的免费额度，仅当月有效。保持后付费关闭，免费及预付费资源耗尽即停用。
   这是普通一句话识别额度，不是大模型实时识别额度。
2. 在[访问管理](https://console.cloud.tencent.com/cam/capi)创建 API 凭证，建议使用仅允许
   一句话识别的子账号。在设备网页填写 SecretId、SecretKey 和 DeepSeek 密钥。
   网页不会读回密钥。保持默认识别地址 `https://asr.tencentcloudapi.com/` 和引擎 `16k_zh`。
3. 固件读取旧配置时不会清除 Wi-Fi、DeepSeek 凭证或对话记忆。旧 multipart 服务会继续
   使用，直到长按确定进入设置，填写新凭证并保存。完整保存时需要重新填写 API 凭证，
   只保存 Wi-Fi 则保留原凭证。

直连模式将 PCM 分块转为 base64 上传，使用 TC3-HMAC-SHA256 和
[腾讯官方 SDK](https://github.com/TencentCloud/tencentcloud-sdk-python/blob/master/tencentcloud/common/abstract_client.py)
实现的 HTTPS unsigned-payload 选项，按该 SDK 对标记字符串计算哈希。
TLS 证书验证保持启用，不会在内存中缓存整段录音或将录音写入 Flash。
电脑服务则对完整 WAV 请求体计算签名。腾讯云可能在 HTTP 200 中返回 API 错误；
此时停止后续 DeepSeek 请求且不更新记忆，也不会显示服务商原始消息或凭证。
真实账号可用性、识别效果和设备内存、时序仍需在本地填写凭证后上板验证。

## 单独配网与私有 Wi-Fi 预置

可以先不填 API 密钥，在网页选择**仅保存 Wi-Fi 并重启**。设备重启后连接已保存的
网络，之后长按确定再添加 API 配置。**沿用设备已保存的 Wi-Fi** 无需把密码读回
浏览器。仅修改 Wi-Fi 会保留 API 配置和对话记忆。加密网络要求 WPA2 或更新协议。
断线后每 5 秒重试一次，30 秒未取得 IP 时提示进入设置，同时继续重试。

预置私有固件时运行 `python3 tools/configure_assistant_wifi.py`，输入 SSID 和隐藏的
密码；也可用 `--input` 读取仅包含 `ssid`、`password` 的本地 JSON 文件。工具按
UTF-8 字节数校验，并将凭据以仅当前用户可读写的权限保存到 Git 忽略的
`.local/assistant-wifi.json`。`--check` 只检查配置，不打印凭据。

正常验证构建会在该本地文件存在时包含预置内容。只有设备尚未保存 Wi-Fi 时才会
将它导入 NVS；已有配置或损坏的 NVS 记录不会被预置覆盖。只配 Wi-Fi 时先显示
联网状态，完成服务设置后才可对话。凭据仍嵌入私有固件，请勿公开其二进制文件
及调试归档。移除本地预置再重新构建即可生成通用固件。修改预置不会覆盖设备
已有 NVS，应通过设置网页修改 Wi-Fi，或明确批准会重置 NVS 的配置烧录。
此流程不会自动烧录设备。

## 启动电脑服务

使用 Python 3.10 或以上，服务仅依赖标准库和 SQLite，无需安装 Python 包。
在仓库根目录执行：

```bash
cp services/voice_gateway/.env.example .env
# 在本地编辑 .env：填写服务密钥、设备令牌及局域网监听地址。
# 生成令牌：python3 -c 'import secrets; print(secrets.token_urlsafe(32))'
set -a
. ./.env
set +a
python3 -m services.voice_gateway
```

环境文件是 shell 文件，值应正确加引号，只加载本地可信内容。`.env` 和 SQLite
文件已被 Git 忽略。不要把密钥放进聊天、截图或提交的文件中。

| 变量 | 含义/默认值 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 必需，DeepSeek 密钥 |
| `TENCENT_SECRET_ID` | 默认语音识别服务必需的腾讯云 SecretId |
| `ASR_API_KEY` | 必需，腾讯云 SecretKey（或所配置兼容服务的密钥） |
| `VOICE_GATEWAY_TOKEN` | 必需，至少 32 个可打印 ASCII 字符的设备令牌 |
| `VOICE_GATEWAY_HOST` | 默认 `127.0.0.1`，接受局域网设备需设为 `0.0.0.0` |
| `VOICE_GATEWAY_PORT` | `8765` |
| `VOICE_GATEWAY_MEMORY_DB` | `~/.local/share/ai-passport/voice-memory.sqlite3` |
| `ASR_BASE_URL` | `https://asr.tencentcloudapi.com` |
| `ASR_MODEL` | `16k_zh` |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` |
| `DEEPSEEK_MODEL` | `deepseek-flash` |
| `BING_SEARCH_ENABLED` | `0`；设为 `1` 后在电脑服务模式回答前加入可选的必应公开网页上下文 |
| `BING_SEARCH_URL` | `https://www.bing.com/search` |

多设备需要独立记忆时，改用 `VOICE_GATEWAY_TOKENS` JSON 对象，将设备标识映射到
各不相同的令牌。设备身份由通过认证的令牌确定。保持电脑唤醒，必要时允许本机
防火墙放行对应端口，在设备设置中填写电脑的局域网地址。

### 可选的必应搜索上下文

电脑服务模式可以在把问题交给 DeepSeek 前搜索必应公开网页 RSS。将
`BING_SEARCH_ENABLED='1'` 写入 `.env` 后，服务最多加入五条受限的 HTTPS 搜索结果
作为不可信参考；必应不可用时会退化为普通回答。设备不会保存必应 API 密钥。
微软已于 2025 年 8 月 11 日退役旧版 Bing Search APIs，因此本功能不使用已退役的
API；如果部署需要微软正式支持的托管检索，应改用 Azure AI Agents 的 Grounding with
Bing Search。

## 记忆及隐私

这里的记忆是有长度限制的持久对话上下文，并非无限事实库，也不会总结全部历史。
直连模式保存最近 3 轮成功问答，问题最多 512 个 UTF-8 字节、回答最多 1024 字节，
截断时始终保留完整字符。电脑模式保存最多 128 轮成功问答，最近 12 轮发给
DeepSeek，超过保留上限的旧问答会过期。服务调用失败不会替换已有记忆。

设备或电脑重启后记忆仍保留。两种模式的历史互相独立，切换模式或修改服务配置
不会合并或清除记忆。换人使用时应明确清除当前历史。清除直连记忆保留 Wi-Fi
及密钥设置；清除电脑记忆只影响当前认证设备的数据。两种操作都不会删除服务商
已经处理的副本或外部备份。

本应用保留 24 KiB NVS 和 PHY 数据，将工厂应用分区调整为 `0x7B0000`，并为单张
壁纸预留 256 KiB 自定义数据分区。显示时直接映射壁纸 Flash，不会把整张图复制到
内部 RAM。此原型未启用 NVS 加密，能物理读取设备的人可能获取凭据及历史。电脑历史为本地 SQLite，应保护
电脑账户和数据库。设备用小缓冲区边录边传，电脑服务不会把音频保存为文件。
应用日志不包含密钥和对话正文。

## 限制与故障处理

设备显示的识别文字上限为 768 个 UTF-8 字节，回答为 1536 字节。过长回答依模式
被拒绝或截断，并显示提示。短问题及简洁回答更适合屏幕和内存限制。表情符号等
不支持的字符会明确标记，字库覆盖说明见[字体资源](../../assets/README.zh_CN.md)。

路由器离线或密码错误时，长按确定重新设置。云服务失败时检查账号权限、额度、
模型及接口地址。TLS 校时错误时检查 NTP 访问并重试。NVS 出错会保留数据，
不会自动擦除整个分区；应诊断或明确清除受影响的历史，而不是擦除全部设置。

## 构建与验收

激活 ESP-IDF 5.5.3 后执行 `./tools/validate.sh`。检查包含独立的状态、配置、记忆
测试，使用模拟服务的电脑网关测试，原有 BSP/示例检查、隔离固件构建和合并镜像
校验。启动路径仅编译语音助手，原有示例源码保留作参考。匹配的固件、ELF、MAP
归档在 `build/firmware/` 下。

可选的本机预览使用 24 KiB LVGL 内存池渲染实际应用界面，包含反复显示最大长度
对话的检查。需要固件构建已下载受管理的 LVGL 源码：

```bash
cmake -S tools/assistant_ui_preview -B build/ui-preview
cmake --build build/ui-preview
(cd build/ui-preview && ./assistant_ui_preview)
```

预览生成 PPM 图像并报告内存池使用情况，用于检查软件渲染和布局，不替代显示硬件
或麦克风输入验收。

实机与真实服务验收另行进行：

1. 检查中文界面、洛天依名称、鲜艳的 `#66CCFF` 主题、标点、长文滚动、三个按键、
   电量及不支持字符提示。分别上传横图和竖图，确认居中裁切、重启后保留，并恢复默认主题。
2. 测试两种模式配网、错误密码、重连、重启、多次进入设置及切换模式。
3. 测试安静和嘈杂环境下的录音识别、提前结束、8 秒上限、服务超时、无效密钥及失败恢复。
4. 告诉助手一个信息，设备断电重启后询问能否记住；确认清除记忆后再次检查。
   电脑模式还需重启电脑服务后重复测试。
5. 测量 TLS、录音、显示及重复请求时的空闲内部堆和最大连续块，检查实际硬件的功耗和音频表现。

每次烧录均需针对已验证的具体固件获得授权。从 `0x0` 写入合并镜像可能重置 NVS；
兼容分区布局的分段烧录可保留它。遵循[固件及数据政策](../development/engineering/firmware-layout.zh_CN.md)。

## 结合上下文的联网搜索与颜文字

直连模式在回答前调用已配置的对话服务规划搜索。规划器接收近期对话和 UTC 日期，
不接收角色人设；返回有长度限制的 JSON 搜索词，闲聊或指代不清时返回空搜索词。
网关模式开启 `BING_SEARCH_ENABLED` 后使用相同策略。规划会增加一次短模型调用，
带来相应延迟和 API 用量。规划失败时跳过搜索，不再直接搜索整段语音。
回答模型会收到搜索词、检索状态和有长度限制的网页摘要，摘要按不可信参考数据处理，
要求核对对象、时间并在证据不足时说明。这属于提示词层面的相关性核对，
不能保证搜索结果或回答绝对正确。

中文字库增加符号后备字体，已验证样例见 `assets/fonts/kaomoji-samples.txt`。
内置提示词允许适度使用简短颜文字；彩色 emoji 和任意 Unicode 仍不支持。
需在实机检查中英文与符号混排、换行及重启后的显示。来源和许可见
[资源清单](../../assets/README.zh_CN.md#语音助手符号后备字库)。
